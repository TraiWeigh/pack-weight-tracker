# R0084P3 — "Cancel | Save" wording in name-edit dialogs

**Date:** 2026-08-18
**Base commit:** 54bcb48 (R0084P2 + report index)
**Test result:** 43 / 43 passed (19 r0084p3 new + 24 r0084 updated)
**TypeScript:** clean (pack-checklist: 0 errors; mockup-sandbox pre-existing TS2322 errors unchanged)

---

## Problem

Both the category rename sheet and the item rename dialog showed **"Rename"** as the confirmation button label. The two-button pattern was "Cancel | Rename". The word "Rename" is redundant given the dialog context and inconsistent with the rest of the UI (which uses "Save" for committing edits). User instruction: change to **"Cancel | Save"**.

---

## What changed

### 1 — Category rename sheet (`MobileFunctionalV3.tsx`, ~line 4612)

```
// Before
aria-label="Confirm rename"   visible: >Rename</button>

// After
aria-label="Save category name"   visible: >Save</button>
```

### 2 — Item rename dialog (`MobileFunctionalV3.tsx`, ~line 4815)

```
// Before
aria-label="Confirm rename item"   visible: >Rename</button>

// After
aria-label="Save item name"   visible: >Save</button>
```

No other attributes, styles, validation logic, data mutation, `data-testid`, or entry-point code was changed.

### 3 — `r0084.spec.ts` — fix stale assertions from R0084P2

R0084P2 changed the item swipe secondary button's `aria-label` from `"Rename <name>"` to `"Edit <name>"`, but the r0084 tests were never updated. This left four assertions with stale `/^Rename /` patterns and one `getByRole('button', { name: 'Confirm rename' })` call that would fail against the new dialog wording. All five corrected:

| Line | Old | New |
|---|---|---|
| 118 | `getByRole('button', { name: 'Confirm rename' })` | `getByRole('button', { name: 'Save category name' })` |
| 190 | `expect(label).toMatch(/^Rename /)` | `expect(label).toMatch(/^Edit /)` |
| 209 | `ariaLabel.replace(/^Rename /, '')` | `ariaLabel.replace(/^Edit /, '')` |
| 257 | `ariaLabel.replace(/^Rename /, '')` | `ariaLabel.replace(/^Edit /, '')` |
| 284 × 2 | `ariaLabel.replace(/^Rename /, '')` (×2) | `ariaLabel.replace(/^Edit /, '')` |
