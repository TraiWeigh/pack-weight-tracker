1. ROOT CAUSE OF MISALIGNMENT
-------------------------------
The sidebar toolbar row ([↓↑] [Background] [Share]) was a sibling div of the
sidebar scrollable container, NOT a child of it. Its padding (lg:pl-3 lg:pr-2)
was always slightly different from the scrollable's padding (lg:pl-1 lg:pr-5).

More critically: the sidebar scrollable carries lg:[scrollbar-gutter:stable],
which reserves ~17 px for a scrollbar track on Windows/Linux. That physical
reservation narrows the usable content box. The toolbar row had no matching
scrollbar-gutter, so its right edge protruded beyond Pack Summary's right edge
regardless of any padding tweak.

023Z attempted a padding patch (lg:pl-1 lg:pr-5 on the toolbar) but it did not
close the gap because scrollbar-gutter is not padding — it is a physical layout
reservation that cannot be compensated from outside the scrollable.

mobile the rendering order is now:

control, which is more logical. The category toolbar is no longer sandwiched
between the sidebar controls and Pack Summary.
