## A. Overview

Two surgical corrections to R0080, zero other changes:

1. **Swipe endpoint restored** — forward swipe from Group 4 now clamps (does not wrap). Only tapping the far-right Next chevron loops Group 4 → Group 1.

2. **Frost retuned to subtle matte** — opacity raised from 82% to 94%, blur reduced from 14 px to 9 px, saturation reduced from 1.25 to 1.05. Categories are barely visible moving underneath. No shine, gloss, gradient, highlight, shimmer, chrome, or reflective treatment.

No changes to Preview/Print, Share, photos, locations, onboarding, auth, database, deployment, or any other feature.

## B. Defects Corrected from R0080

### Defect 1 — Swipe erroneously wrapped (R0080 introduced)

**R0080 original:** swipe threshold branch changed to `if (dx < -THRESHOLD) settleRef.current((cur + 1) % NUM_BOX_GROUPS)` — the endpoint guard was removed, causing a forward swipe from Group 4 to wrap to Group 1.

**Requirement:** only tapping the Next chevron should loop; swipe should clamp at endpoints.

**R0080P2 fix (line 949):**
```typescript
// R0080 (wrong):
if (dx < -GROUP_SWIPE_THRESHOLD) settleRef.current((cur + 1) % NUM_BOX_GROUPS);

// R0080P2 (correct):
if (dx < -GROUP_SWIPE_THRESHOLD && cur < NUM_BOX_GROUPS - 1) settleRef.current(cur + 1);
```

`goRight` (bound to the tap-Next chevron) still uses modular arithmetic and still wraps. The visual live-drag clamp was already correct and is unchanged.

---

### Defect 2 — Frost values too strong (R0080 was too aggressive)

**R0080 original:** `blur(14px) saturate(1.25)` outer, `rgba(42, 87, 64, 0.82)` inner — 18% bleed-through was too visible; blur and saturation were heavier than a subtle matte.

**Requirement:** ~92–96% opacity (start near 94%), ~8–10 px blur, mild saturation ~1.00–1.08. Categories barely visible. No gloss or shine.

**R0080P2 fix (lines 3413–3420):**

| Property | R0080 | R0080P2 |
|----------|-------|---------|
| `backdropFilter` | `blur(14px) saturate(1.25)` | `blur(9px) saturate(1.05)` |
| `WebkitBackdropFilter` | `blur(14px) saturate(1.25)` | `blur(9px) saturate(1.05)` |
| Inner panel `background` | `rgba(42, 87, 64, 0.82)` | `rgba(42, 87, 64, 0.94)` |

Alpha 0.94 = 94% opacity → 6% bleed-through. At 9 px blur those underlying categories are barely readable — matte frosted glass effect, not a clear window. No brightness(), no shine overlay, no gradient.

`summaryRef.getBoundingClientRect()` geometry is identical — R0076P3 long-category positioning is unaffected.

## G. Design Notes

- **Swipe vs tap distinction preserved** — swiping has always been a "quick navigation" gesture between adjacent groups. It should never teleport (wrap). Only the explicit Next tap should loop, because the user is deliberately seeking the wrapping behavior.
- **Matte frost intent** — at 94% opacity and 9 px blur, the bar reads as solid green at a glance. On close inspection, with categories moving underneath, there is a very faint frosted-glass shimmer. This matches "barely able to see categories moving underneath."
- **No render cost increase** — `blur(9px)` is less expensive than `blur(14px)`. The change strictly reduces GPU compositing cost.
- **summaryRef geometry** — identical. The sticky bar's `height`, `top`, `margin`, and `getBoundingClientRect()` are all unchanged. R0076P3 long-category inner-scroll positioning is unaffected.
