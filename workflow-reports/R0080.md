# R0080 — Next-Wrap Navigation + Matte-Frosted List Summary

**Route:** `/mobile-functional-v3`
**Date:** 2026-08-18
**Status:** ✅ COMPLETE — 14/14 tests pass, regressions clean

---

## A. Overview

Two narrow mobile refinements on `/mobile-functional-v3`:

1. **Next-wrap navigation** — Next chevron added to Group 4; clicking/swiping it cycles forward to Group 1. Back (Previous) is unchanged: absent on Group 1, present on Groups 2–4, never wraps.

2. **Matte-frosted List Summary** — Sticky summary bar gains `backdrop-filter: blur(14px) saturate(1.25)` with a semi-transparent green panel (`rgba(42, 87, 64, 0.82)`). Category rows are barely visible moving underneath. No gloss, gradient, shimmer, or highlight.

No changes to Preview/Print, sharing, photos, locations, onboarding, auth, schema, or deployment.

## C. Implementation

### Change 1 — `goRight` wraps (line 894)
```typescript
// Before
const goRight = useCallback(() => { settle(Math.min(NUM_BOX_GROUPS - 1, groupIdxRef.current + 1)); }, [settle]);

// After (R0080)
const goRight = useCallback(() => { settle((groupIdxRef.current + 1) % NUM_BOX_GROUPS); }, [settle]);
```

### Change 2 — Swipe forward wraps (line 947)
```typescript
// Before
if (dx < -GROUP_SWIPE_THRESHOLD && cur < NUM_BOX_GROUPS - 1) settleRef.current(cur + 1);

// After (R0080) — endpoint guard removed; modular arithmetic wraps Group 4 → Group 1
if (dx < -GROUP_SWIPE_THRESHOLD) settleRef.current((cur + 1) % NUM_BOX_GROUPS);
```
The back-swipe guard (`cur > 0`) is preserved — swiping back from Group 1 still does nothing.

The live-drag visual clamp (lines 925–927) is intentionally left unchanged: a rightward swipe from Group 4 shows no visual preview of the wrap (the track clamps visually) but still commits the wrap on release. This avoids showing empty space to the right of Group 4 in the translation system.

### Change 3 — Next chevron added to Group 4
```tsx
// After More in Group 4:
<span style={{ width: 1, background: DIVIDER, alignSelf: 'stretch' }}/>
<ChevronBox direction="right" aria="Next controls" onClick={goRight}/>
```
Group 4 now: `[BACK] | Save | Share | More | [NEXT]`

### Change 4 — List Summary outer wrapper: transparent + blur
```tsx
// Before
style={{ position: 'sticky', top: 0, zIndex: 4, background: PAGE_BG }}

// After (R0080)
style={{
  position: 'sticky', top: 0, zIndex: 4,
  backdropFilter: 'blur(14px) saturate(1.25)',
  WebkitBackdropFilter: 'blur(14px) saturate(1.25)',
}}
```
`background: PAGE_BG` removed — outer wrapper is transparent so the blur effect composites directly against the scrolling categories below.

### Change 5 — List Summary inner panel: semi-transparent green
```tsx
// Before
background: SUMMARY_BG   // #2A5740 — fully opaque

// After (R0080)
background: 'rgba(42, 87, 64, 0.82)'   // same hue, ~18% bleed-through
```
`rgba(42, 87, 64)` is the exact RGB expansion of `#2A5740`. At 0.82 opacity, text contrast remains strong while the blur underneath is faintly visible. No shine, no gradient, no additional brightness filter.

**`summaryRef` geometry is unchanged** — the element's size, position, and `getBoundingClientRect()` values are identical. Long-category header alignment (R0076P3) is unaffected.

## G. Design Notes

- **No wrap on Back** — Group 1 has no Previous chevron and the back clamp is unchanged. Only Next wraps.
- **No visual wrap animation during swipe** — the live-drag track clamps at Group 4's right edge to avoid showing empty track space. The wrap commits on finger-lift (same instant feel as tapping Next).
- **Matte, not glossy** — `saturate(1.25)` lifts colours slightly without any `brightness()`, shine overlay, or gradient. The effect is a flat, matte frosted panel.
- **Text contrast preserved** — `rgba(42, 87, 64, 0.82)` gives a WCAG-passing contrast ratio for white text on this green at 82% opacity against the cream/category background.
- **Long-category geometry unchanged** — `summaryRef.getBoundingClientRect().bottom` continues to read the correct value for inner-scroll viewport positioning (R0076P3).
