## What was built

A half-screen sliding navigation drawer with:

- **Hamburger button** in the app bar (top-left for right-handed, top-right for left-handed). Green `#2A5740` colour on the white header bar. 44×44 px touch target.
- **Five nav rows** (all ≥ 44 px tall):
  - Home — closes the drawer and returns to the list
  - Master Library — disabled, labelled "Coming soon" in the sublabel, `aria-disabled="true"`, `aria-label` includes "not yet available"
  - My Lists — opens the Locker deck
  - Help & Tutorials — pushes the Help footer page onto the screen stack
  - Settings — opens the More deck and activates the List Settings card directly
- **Handedness toggle** in the panel footer — persists to `localStorage` key `tw-handedness`; mirrored on reload
- **Swipe to close** — drag panel ≥ 50 px toward its edge; axis-locks after 6 px of movement to avoid conflicts with vertical scroll
- **Backdrop** — `rgba(0,0,0,0.40)`; clicking outside the panel closes the drawer
- **Always-rendered** — panel is in the DOM at all times; open/close is purely CSS `transform` so the close animation is never cut short
- `data-open="true|false"` on `<nav>` for reliable Playwright state assertions
- `aria-hidden="true"` on closed panel (semantics) and on the backdrop (decorative)

## Z-index placement

```
40  Bottom nav (BoxGroupBar)
45  Drawer backdrop           ← new
46  Drawer panel              ← new
50  Full-screen overlays (Preview, Checklist, screenStack pages)
60  Footer-page / edit-category overlays
200 Confirmation dialogs
9999 Toast
```

Drawer sits above the bottom nav but below all full-screen overlays, so opening Preview always renders on top of a closed drawer.

## Design decisions

- **Panel width** 55% / min 160 / max 240 px — "about half" the screen; narrow enough to see content behind it
- **Open 200 ms / Close 180 ms** `cubic-bezier(0.4, 0, 0.2, 1)` — matches Material Design spec
- **`data-open` attribute** instead of conditional mounting — preserves close animation and avoids remounting side effects
- **Backdrop z=45, panel z=46** — above bottom-nav (40), below all full-screen overlays (50+); Preview, Checklist, and screenStack pages always appear on top
- **Settings shortcut** uses `pendingCardActivation` effect pattern — deferred card activation fires after the More deck's first render to avoid `setActiveCardId(null)` clobbering
- **Swipe gesture** uses window `pointermove/pointerup` listeners (same pattern as drag-to-reorder), never `setPointerCapture` — consistent with BoxGroupBar pointer-capture lessons from memory
