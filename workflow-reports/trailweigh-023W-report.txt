2. CODE/BEHAVIOR ADDED
----------------------
New state in Checklist.tsx:
  const [sidebarAllOpen, setSidebarAllOpen] = useState<boolean | null>(null);
  const [sidebarOpenSeq, setSidebarOpenSeq] = useState(0);

New control UI (in right toolbar panel, before BgEdit+Share group):
  A segmented Open/Close pill matching the existing category Open/Close visually.
  - "Open": setSidebarAllOpen(true) + setSidebarOpenSeq(s => s + 1)
  - "Close": setSidebarAllOpen(false) + setSidebarOpenSeq(s => s + 1)
  Uses the same barBgStyle / barColor / barTextColor / barFont style treatment as
  the existing category Open/Close control.

Force-open pattern in each sidebar component (same as GearCategory):
  useEffect(() => {
    if (forceOpen !== null && forceOpen !== undefined) {
      setOpen(forceOpen);   // or setSummaryOpen / setChartOpen
    }
  }, [forceOpen, forceOpenSeq]);

  forceOpenSeq increments on every click, so the effect fires even when the boolean
  value is unchanged (e.g., Close clicked twice in a row).

  Initial value sidebarAllOpen = null: the useEffect guard (forceOpen !== null &&
  forceOpen !== undefined) prevents firing on mount, so panels start in their
  default open/closed state (Locker=open, Pack Summary=closed, etc.).

4. OPEN-ALL AND CLOSE-ALL BEHAVIOR
-----------------------------------
Click Open → setSidebarAllOpen(true) + setSidebarOpenSeq increments
  → useEffect fires in all four panels → each panel's open state set to true.

Click Close → setSidebarAllOpen(false) + setSidebarOpenSeq increments
  → useEffect fires in all four panels → each panel's open state set to false.

Works regardless of current state:
  - If all four are already closed, Open opens all four.
  - If only one is open, Close closes that one (and leaves the others closed).
  - If two or three are open, Close closes every open one.
  - If all are already closed, Close sets all to false (no-op, no error).
