# R0081 — Preview: show all gear items, not just checked ones

**Date:** 2026-08-18  
**Scope:** `MobileFunctionalV3.tsx` → `PreviewOverlay`; `PreviewModal.tsx` → `PreviewBody`  
**Tests:** 18 pass / 18 total  
**Screenshots:** `screenshots/r0081-01-*` … `r0081-04-*`

---

## Problem

`PreviewOverlay` passed `filterToChecked={true}` to `PreviewBody`, which silently dropped every unchecked item. A 77-item list with 32 checked would show only 32 items in Preview — giving no sense of the complete gear list and making print/download outputs incomplete.

Additionally `PreviewOverlay` had zero local state: there was no way to see the full list or toggle check states without mutating the working list.

---

## Changes

### `artifacts/pack-checklist/src/components/PreviewModal.tsx`
- Added optional `dimUnchecked?: boolean` prop to `PreviewBodyProps` (default `true`)
- `PreviewBody` now respects `dimUnchecked`: opacity is set to `0.5` only when `dimUnchecked=true` and the item is unchecked
- With `dimUnchecked={false}` (how `PreviewOverlay` uses it), all rows render at full opacity

### `artifacts/pack-checklist/src/pages/MobileFunctionalV3.tsx`
- Added `useMemo` to React import
- Added `CheckSquare` to lucide-react import (alongside `Undo2` which was already present)
- **Rewrote `PreviewOverlay`** — now holds all display state locally:
  - `previewChecks: Record<string,boolean>` — initialised from `sandbox.items` on mount; **never writes back to the working list**
  - `beforeClear: Record<string,boolean> | null` — `null` = not yet cleared (pill shows "Clear Checks"); non-null = snapshot for undo (pill shows "Undo")
  - `displayData: PackState` — `useMemo`-computed copy of `sandbox.items` with `checked` values overridden from `previewChecks`
  - `handleClear` / `handleUndo` callbacks
  - **Pill button** — full-width, `borderRadius: 100`, `minHeight: 44px`, `background: #2A5740`; label and `data-testid` flip between `preview-clear-btn` / `preview-undo-btn` when state changes
  - `filterToChecked={false}` — all items shown regardless of check state
  - `dimUnchecked={false}` — all rows render at full opacity
  - `data-testid="preview-overlay"` on root div
  - Updated note banner: *"All items in this list — tap the printer icon to print or download."*
  - State auto-discards on close (component unmounts when `showPreview=false`)

## Design decisions

- **Preview-local state only.** `previewChecks` and `beforeClear` live inside `PreviewOverlay`. Because `showPreview=false` unmounts the component, all state auto-resets on close — no explicit `useEffect` cleanup needed.
- **No new `PreviewBody` logic.** The only change to `PreviewBody` is the `dimUnchecked` guard on the opacity line. All filtering, ordering, and weight-summary logic is untouched.
- **Working list immutability.** `sandbox` is read once into `previewChecks` on mount; `displayData` is computed without ever calling `setSandbox`. Tests R81-12 and R81-13 confirm the working-list selected count is unchanged after both Clear and Undo.
- **One-level Undo only.** Undo reverts the single Clear action; multiple sequential Clear→Undo cycles each reset back to the pre-Clear snapshot. (Multi-step undo is not required by the spec.)
