## Features Implemented

### 1. Per-item Location (R0085-Loc)

- **Data model:** `GearItem.locationId?: string` references a `PackLocation { id, name }` record stored in `SandboxStore.locations: PackLocation[]`.
- **Handlers:** `addLocation`, `renameLocation`, `removeLocation`, `setItemLocation` — all via `useCallback` + `mutateSandbox`.
- **Locker save paths fixed:** all 3 Locker save sites (`handleSaveNow` update, `handleSaveNow` create, `handleSaveAsConfirm`) now include `locations` in the serialized store object (`as unknown as LockerEntry['store']` cast to avoid type widening while retaining runtime data).
- **Load path** (pre-existing): `locations: (store as any).locations ?? []` — already in place.

### 2. Location Picker Sheet (R0085-LocPicker)

- **Trigger:** "No location" button inside item accordion opens `[data-testid="location-picker-sheet"]`.
- **Filter/create input** (`[data-testid="location-picker-input"]`): filters existing locations; pressing Enter with an unmatched name creates a new location and assigns it in one step.
- **Existing location rows:** tap to assign; Edit pencil opens inline rename; Trash deletes location and unlinks all items.
- **Create button** (`[data-testid="location-picker-create"]`): appears when filter text doesn't match any existing location exactly.
- **Remove** (`[data-testid="location-picker-remove"]`): appears when the current item already has a location assigned.
- **Escape / backdrop tap** dismisses without changes.

### 3. Category|Location View Bar (R0085-ViewBar)

- Rendered between sticky header and scrollable content.
- Only visible when `allItems.some(i => i.locationId)` — hidden by default on fresh demo.
- Two buttons: `[data-testid="view-mode-category"]` and `[data-testid="view-mode-location"]`, styled with `aria-pressed`.

### 4. Location View (R0085-LocView)

- When `viewMode === 'location'`, `[data-testid="location-view"]` is rendered; the catListRef div is set to `display: none` (preserving DOM, avoiding re-mount cost).
- Items grouped by their assigned location; unassigned items appear in a "No Location" group.
- Each item row shows thumbnail (if photo exists), display name, category, weight/qty, and an "Edit" button that switches back to Category view and jumps to that item's accordion.
- Location group headers show MapPin icon, location name, and item count.

### 5. Real Item Photos (R0085-Photo)

- **Replaced disabled stub** with a live Photo row.
- `GearItem.photoDataUrl?: string` stores a canvas-compressed JPEG (max 800 px, 72% quality).
- **Handlers:** `handlePhotoAdd(cat, id, file)` compresses then calls `updateItem`; `handlePhotoDelete(cat, id)` clears the field.
- **Photo edit sheet** (`[data-testid="photo-edit-sheet"]`): Take New Photo (camera capture), Upload New Photo (file picker), Delete Photo (only if photo exists), Cancel.
- Hidden `<input type="file">` elements (`photoCameraRef`, `photoUploadRef`) attached to stable refs — device original is never modified.
- **Inline photo viewer**: toggled with View/Hide buttons inside the accordion; shows image at max 300 px height.

### 6. Category Direct-Edit (R0085-CatEdit)

- Swipe Edit on a category bar now sets `catDirectEditFor` / `catDirectEditValue` state instead of opening the Category Options sheet.
- `[data-testid="cat-direct-edit-dialog"]` — bottom sheet with:
  - Pre-filled input showing current category name.
  - Cancel: dismisses, no change.
  - Save (disabled when unchanged or empty): calls `sandboxRenameCategory` then dismisses.
  - Enter key triggers save; Escape triggers cancel.
- Red swipe button (delete) still routes through Category Options sheet (unchanged).

### 7. Auto-switch to Edit Group on Mutation (R0085-AutoSwitch)

- `BoxGroupBarProps.groupControlRef?: React.MutableRefObject<{ switchGroup(idx: number): void } | null>` added.
- Inside `BoxGroupBar`, a `useEffect` writes `{ switchGroup }` to `groupControlRef.current` after the settle ref is set up.
- `mutateSandbox` appends `navGroupRef.current?.switchGroup(1)` — switches to group index 1 (Back | Undo | Redo | Reset | Next) on every data-mutating call.
- Undo/Redo bypass `mutateSandbox` (call `setSandbox` directly), so they don't re-trigger the switch.
- `BoxGroupBar` call site updated: `groupControlRef={navGroupRef}`.
