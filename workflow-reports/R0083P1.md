## What changed

### 1 — Wedge and checkbox restored to original (left) positions

R0083's CSS `order` changes are fully reverted. The coloured category wedge and the item checkbox are back on the **left side** of their rows in all handedness modes, matching the pre-R0083 layout.

Reverted edits:
- Wedge button: removed `order`, `clipPath` flip, and `padding` swap — restored to original left-pointing polygon and `paddingRight: WEDGE_POINT / 2`
- Content grid: removed `order: 1` pin (not needed without the wedge reorder)
- Checkbox button: removed `order: handedness === 'right' ? 2 : 0`
- Expand area: restored `paddingRight: 14` (removed `paddingLeft` conditional)

### 2 — Hamburger fixed always on the LEFT

R0082 rendered two conditional hamburger buttons — one on the left for right-handed mode, one on the right for left-handed mode. Replaced with a single unconditional button always on the left for everyone. The `handedness` state is still used by the drawer's internal handedness toggle, but no longer controls the hamburger position.

### 3 — Open/Close secondary action added to category swipe reveal

When a category row is swiped left, the revealed area now shows **two buttons** instead of one:

| Button | Position | Colour | Action |
|---|---|---|---|
| **Open** / **Close** | Left of Delete | `#2A5740` brand green | Toggles the category accordion |
| **Delete** | Rightmost | `#B03A2E` red | Opens delete-confirmation flow (unchanged) |

Implementation: `SwipeDeleteRow` gained an optional `secondaryAction?: { label, icon, onAction }` prop. When present, `totalRevealW = SWIPE_ACTION_W × 2 = 176 px`; all swipe math (clamp, half-way threshold, resting offset) uses `totalRevealW`. Item rows pass no `secondaryAction` and are entirely unaffected. The secondary button carries `data-testid="swipe-secondary-action"` for Playwright assertions.

The label reflects live state: **Open** when the category is currently closed, **Close** when it is open. Tapping it calls `handleCatToggle(catName)` — the same function the wedge uses — and closes the swipe reveal in one tap.
