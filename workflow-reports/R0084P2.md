# R0084P2 — Swipe-label accessibility repair

**Date:** 2026-08-18

**Test result:** 36 / 36 passed
**TypeScript:** clean (pack-checklist: 0 errors; mockup-sandbox pre-existing TS2322 errors unchanged)

## Problem

The secondary (green) swipe-action button used a single `label` string for both its visible rendered text and its `aria-label`. For a category called "Sleep System" the button showed the full string `Edit Sleep System category` as visible text inside the narrow 88 px slot, causing word-wrap. The item row showed `Rename Big Agnes Copper Spur HV UL2` (or similar) in the same slot.

---

## What changed

### 1 — `SwipeDeleteRow` interface extended (`MobileFunctionalV3.tsx`)

Added an optional `visibleLabel` field to the `secondaryAction` prop type:

```tsx
// Before
secondaryAction?: { label: string; icon: React.ReactNode; onAction: () => void };

// After
secondaryAction?: { label: string; visibleLabel?: string; icon: React.ReactNode; onAction: () => void };
```

The render now uses `visibleLabel` for button text when provided, and always uses `label` for `aria-label`:

```tsx
// aria-label — unchanged, always the full descriptive string
aria-label={secondaryAction.label}

// Visible text — short label when provided, falls back to label
{secondaryAction.visibleLabel ?? secondaryAction.label}
```

`whiteSpace: 'nowrap'` also added to the button style to prevent future wrapping if a longer `visibleLabel` is ever used.

### 2 — Category swipe call site

```tsx
// Before
label: `Edit ${catName} category`,

// After
label: `Edit ${catName} category`,   // aria-label only — unchanged
visibleLabel: 'Edit',               // visible button text
```

### 3 — Item swipe call site

```tsx
// Before
label: `Rename ${displayName}`,

// After
label: `Edit ${displayName}`,   // aria-label — updated wording to match "Edit"
visibleLabel: 'Edit',          // visible button text
```

Note: the item `label` wording was also aligned from "Rename" to "Edit" to match the category button and the user's instruction that both visible buttons show "Edit".
