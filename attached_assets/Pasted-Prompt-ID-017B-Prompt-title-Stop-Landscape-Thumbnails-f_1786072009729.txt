Prompt ID: 017B
Prompt title: Stop Landscape Thumbnails from Shaking on Hover

Fix the visible shaking or jitter that occurs when the mouse cursor moves over the built-in Landscape background thumbnails.

This is a focused visual-stability repair.

Prompt 017A has been user-tested and Hide is now working.

Do not redesign Background Edit, Themes, custom photo collections, Hide, Preview, Imperial/Metric, or the checklist layout.

# CONFIRMED USER-REPORTED DEFECT

In Background Edit:

- The user selects or views the built-in Landscapes theme.
- Moving the cursor across Landscape thumbnails causes the images or tiles to shake, jump, resize, or shift.
- The movement can repeat as the pointer crosses the image or its controls.
- The problem occurs only with built-in Landscape thumbnails.
- Custom-theme photo thumbnails do not show the same shaking.

The final result must be:

- Landscape thumbnails remain completely stationary during hover.
- Hover feedback may still appear, but it must not change tile size, position, spacing, or image crop.
- Custom-theme thumbnails must continue working as they do now.

- Normal state
- Mouse hover

# PART 4 — REMOVE LAYOUT-SHIFTING HOVER EFFECTS

If the Landscape thumbnail currently uses a hover scale or transform, remove that movement.

Examples that must not remain on the tile or image:

- `hover:scale-105`
- `hover:scale-[1.02]`
- `transform: scale(...)`
- Positive or negative translate values
- Width/height enlargement
- Changing aspect ratio
- Changing image crop on hover

A nonmoving hover treatment is allowed, such as:

- Stable box shadow
- Stable overlay
- Slight brightness change
- Slight opacity change
- Border-color change using the same border width
- Background-color change
- Cursor change

Do not use a hover treatment that makes the thumbnail appear to jump.

Avoid `transition-all`.

Transition only visual properties that cannot affect layout, such as:

- `opacity`
- `filter`
- `box-shadow`
- `border-color`
- `background-color`

# PART 5 — STABILIZE BORDERS AND SELECTED STATE

The selected Landscape thumbnail currently uses a visible border and checkmark.

Preserve that indication without changing the tile’s size.

Requirements:

- Reserve the selected-border space in every state.
- Use the same border width for selected and unselected tiles.
- Unselected tiles may use a transparent border.
- Selected tiles may change only the border color.
- Do not add a thicker border only after selection or hover.
- Do not change padding when selected.
- Do not change grid dimensions when the checkmark appears.

The selected checkmark must:

- Remain clearly visible
- Be absolutely positioned over the thumbnail
- Not occupy normal layout space
- Not push or resize the image
- Not intercept pointer movement in a way that repeatedly toggles hover state
- Remain keyboard and screen-reader compatible where applicable

# PART 6 — STABILIZE HOVER CONTROLS

If a Landscape tile contains any hover overlay, label, tooltip, icon, or control:

- Keep it inside the fixed tile boundary.
- Position it absolutely.
- Do not insert it into normal document flow during hover.
- Do not change the tile’s dimensions.
- Use `pointer-events` carefully so crossing the overlay does not repeatedly trigger mouse-enter and mouse-leave events.

If an overlay is decorative:

- Consider `pointer-events: none`.

If it is interactive:

- Keep it within a stable parent hover area.
- Do not attach hover detection only to the underlying image if the overlay becomes a separate pointer target.
- Prevent rapid parent/child hover toggling.

Do not remove accessibility merely to stop movement.
