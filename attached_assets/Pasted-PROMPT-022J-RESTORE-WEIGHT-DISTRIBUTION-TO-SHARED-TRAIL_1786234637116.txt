PROMPT 022J — RESTORE WEIGHT DISTRIBUTION TO SHARED TRAILWEIGH LINKS

GOAL

Restore the Weight Distribution panel to the FULL Shared TrailWeigh Link experience.

USER-TESTED PROBLEM:

The Shared TrailWeigh Link currently includes the shared gear list and other shared-list features, but the Weight Distribution panel is missing.

Weight Distribution should be available on the full Shared TrailWeigh Link just as it is on the normal TrailWeigh checklist, using the data contained in the shared snapshot.

IMPORTANT:

Do NOT add Weight Distribution to the simplified "Checkable Packing List" view.

That view should remain focused on packing only.

==================================================
0. BACKUP / CHANGE PROTECTION
==================================================

Before making ANY changes:

1. Create the normal Replit project checkpoint/backup.

2. Inspect the current implementation before editing.

3. Make the smallest reasonable change required to restore Weight Distribution to the full Shared TrailWeigh Link.

4. Do NOT refactor unrelated components or application architecture.

5. Preserve:
   - Existing saved user files
   - Shared snapshots
   - Authentication
   - Permissions
   - All previously user-verified fixes

6. After implementation, inspect the COMPLETE final diff.

7. Revert any unrelated changes before completing the prompt.

==================================================
1. FULL SHARED LINK VS CHECKABLE PACKING LIST
==================================================

TrailWeigh now has two distinct shared experiences.

A. FULL SHARED TRAILWEIGH LINK

This should include the useful TrailWeigh analysis/viewing features available to a shared viewer, including:

- Shared gear categories
- Pack Summary
- Weight Distribution
- Existing allowed shared-list controls
- Existing background
- Existing shared-list viewing/temporary interaction

B. CHECKABLE PACKING LIST

This is intentionally simpler.

It should remain focused on:

- Gear categories/items
- Item descriptions
- Quantities where useful
- Packing checkboxes
- Printing

DO NOT add Weight Distribution to the Checkable Packing List.

Do not make the simple packing checklist into another full TrailWeigh interface.

==================================================
2. INSPECT THE PRIVATE WEIGHT DISTRIBUTION IMPLEMENTATION
==================================================

Before implementing the shared version, inspect the normal/private Checklist implementation of Weight Distribution.

Determine:

- Which component renders Weight Distribution.
- What data it receives.
- How category totals are calculated.
- How checked gear affects the calculation.
- How Base Weight / Expendables / worn or excluded classifications affect it, if applicable.
- How Imperial / Metric affects displayed values.
- How its collapsed/expanded state is controlled.
- Where it is positioned relative to Pack Summary.

Reuse the existing Weight Distribution component and calculation logic wherever practical.

Do NOT create a second independent weight-distribution calculation system unless technically unavoidable.

There should be one consistent source of truth for the calculations.

==================================================
3. USE THE SHARED SNAPSHOT DATA
==================================================

Weight Distribution on the Shared Link must be calculated from the SAME SHARED SNAPSHOT that supplies the shared gear list.

Do NOT query or modify the owner's live private file simply to render Weight Distribution.

If a Shared Link represents a snapshot of the list at the time it was shared, Weight Distribution must represent that snapshot as well.

Example:

At the time a list was shared:

Shelter = 2.1 lb
Sleep System = 2.4 lb
Clothing = 1.8 lb
Kitchen = 0.8 lb

The Shared Link Weight Distribution should reflect those shared values.

If the owner later changes their private list, do not silently alter an existing shared snapshot unless that is already the intentional TrailWeigh sharing architecture.

Preserve the current shared-snapshot model.

==================================================
4. MATCH THE NORMAL TRAILWEIGH CALCULATIONS
==================================================

For the same gear snapshot, the Shared Link Weight Distribution should produce the same category distribution as the normal TrailWeigh checklist.

Do not simplify or approximate the calculations.

Preserve existing rules involving:

- Checked/selected gear
- Quantity
- Item weight
- Category assignment
- Base Weight classifications
- Consumables / Expendables
- Worn or excluded items
- Any other current weight-distribution rules

Use only calculations that already exist in TrailWeigh.

Do not invent new classifications.

==================================================
5. PANEL PLACEMENT
==================================================

Add Weight Distribution to the full Shared TrailWeigh Link in the same logical location used by the normal Checklist.

Inspect the private Checklist before deciding the exact order.

Where practical, mirror the relationship between:

- Weight Distribution
- Pack Summary

Do not place Weight Distribution somewhere unrelated merely because there is available space.

The Shared Link should feel like a read-only/shared version of TrailWeigh, not a separately designed application.

==================================================
6. START COLLAPSED
==================================================

Prompt 022I established the clean-start rule for Shared Links.

Weight Distribution must follow that rule.

Whenever a Shared TrailWeigh Link is:

- Opened
- Reopened
- Refreshed

Weight Distribution must start:

COLLAPSED

Its header/title remains visible.

The recipient may click the title/header row to expand it.

After expansion:

- It stays open normally during the current session.
- It can be collapsed again.
- It must not be continually forced closed.

On refresh/reopen:

- It returns to collapsed.

==================================================
7. ENTIRE HEADER ROW CLICKABLE
==================================================

Use the same accordion/disclosure behavior established elsewhere in TrailWeigh.

For Weight Distribution:

- Entire title/header row is clickable.
- Do not require clicking only the small chevron.
- Show a disclosure chevron/caret.
- Provide hover/focus feedback.
- Support Enter and Space for keyboard users.
- Use appropriate aria-expanded semantics.

This is a collapsible panel/accordion section, not a dropdown menu.

==================================================
8. PRESERVE SHARED CHECKED GEAR STATE
==================================================

Weight Distribution must reflect the gear state contained in the shared snapshot.

Do not reset gear checkboxes merely because the Weight Distribution panel is added.

Example:

If the shared snapshot contains:

Tent — checked
Quilt — checked
Rain Jacket — checked
Camp Chair — unchecked

Weight Distribution must use the appropriate checked/shared state according to the same rules as the private Checklist.

Adding or opening Weight Distribution must not modify these items.

==================================================
9. TEMPORARY RECIPIENT CHANGES
==================================================

Preserve the existing Shared Link temporary-interaction model from Prompt 022I.

If the full Shared Link currently allows a recipient to make temporary session checkbox changes, Weight Distribution should update consistently with those temporary viewer-side changes where the normal current TrailWeigh behavior supports live recalculation.

However:

- Those temporary changes must remain viewer/session-only.
- They must not write back to the owner's saved original.
- They must not change the shared snapshot stored for the owner.
- They must not change the owner's Locker.

If the current shared architecture intentionally does NOT recalculate analysis from temporary viewer changes, preserve that behavior instead.

Inspect the existing shared calculation flow and document the result.

Do not invent new persistence behavior.

==================================================
10. IMPERIAL / METRIC
==================================================

If the full Shared Link currently allows the viewer to switch between Imperial and Metric:

Weight Distribution must display consistently with that selected unit system.

Use the existing conversion/display logic.

Do not create separate conversion formulas just for the shared page.

Changing units must not modify the owner's saved data.

==================================================
11. READ-ONLY / PERMISSION PROTECTION
==================================================

Weight Distribution is an ANALYSIS / DISPLAY feature.

It must not give a Shared Link viewer any additional ownership permissions.

The recipient must still NOT gain access to:

- Rename
- Delete
- Owner-only Locker controls
- Private file management
- Permanent owner-data modification

Opening or interacting with Weight Distribution must never modify the owner's original file.

Keep that view simple.

Weight Distribution belongs only on the FULL Shared TrailWeigh Link.
