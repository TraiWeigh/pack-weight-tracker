CURRENT USER-VERIFIED NAME DESIGN

The visible TrailWeigh item row is:

TYPE | NAME | MOVE | WEIGHT | QTY | TOTAL

The user wants this simple meaning:

TYPE
= what kind of item it is.

NAME
= the actual manufacturer/product/model name, when the source provides one.

WEIGHT
= per-item weight.

QTY
= quantity.

TOTAL
= calculated total.

Worn/consumable/status/notes/specification text must not be used as NAME.

CURRENT PROBLEM

Prompt 024R successfully stopped obvious worn/status notes such as:
- Worn while hiking
- Pair weight
- Worn item

from becoming NAME.

But current Test 01 / Test 02 previews still show other non-product text in NAME, including examples such as:

- 110 g fuel canister
- 1 L bottle
- 10,000 mAh
- Main pack
- Carried layer
- Reusable
- Rechargeable
- Three daily portions

These are descriptions, specs, capacities, notes, status, or generic attributes.
They are not manufacturer/product/model names.

PRIMARY GOAL

During CSV/XLSX import:

1. Prefer explicit product-identity source fields for TrailWeigh NAME.

3. If no actual product/model name is available, leave NAME blank.
4. Do NOT invent or infer a manufacturer/model.
5. Update the Scan Gear List warning text from “missing descriptions” to “missing names.”
