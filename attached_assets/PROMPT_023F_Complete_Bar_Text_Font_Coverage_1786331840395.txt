PART B — TEXT COLOR MUST REACH ALL BAR/PILL CONTENT
==================================================

==================================================
5. TEXT COLOR SCOPE
==================================================

When a user chooses Text Color, ALL textual and iconographic content within the
customizable bars and pills must use that selected color unless a legitimate
state treatment intentionally modifies opacity.

This includes BOTH primary and secondary content.

Examples that MUST follow Text Color:

CATEGORY BAR:
- category title
- packed count ("2 / 4 packed")
- weight number
- unit labels (oz, lbs, g, kg)
- secondary weight value
- +Base pill text
- +Base icon if present
- drag/reorder handle
- trash icon
- chevrons/disclosure arrows
- other status text/icons inside the bar

PANEL BARS:
- Pack Summary text/icon
- Weight Distribution text/icon
- Scan Gear List text/icon
- Locker text/icon
- secondary text visible in their bars/headers

PILLS:
- File Name text
- Preview text/icon
- Background Edit text/icon
- Share text/icon
- Open/Close text
- Hide text/icon
- Imperial/Metric text
- Desert/Trail text/icon
- +Base text/icon

==================================================
6. SECONDARY TEXT MUST NOT KEEP OLD COLORS
==================================================

Do not leave secondary text using old hard-coded gray/white/muted classes when
the user selected a custom Text Color.

If secondary text needs to remain visually secondary:
- preserve hierarchy using opacity
- preserve weight/font-size differences
- preserve spacing

But the base color should still derive from the selected Text Color.

Example:
selected Text Color = black

Then:
- primary text may be black at full opacity
- secondary text may be black at reduced opacity

Do NOT use unrelated hard-coded gray.

==================================================
7. ICONS
==================================================

Icons inside bars/pills should inherit currentColor where practical.

This includes:
- chevrons
- trash
- drag handles
- Base icon
- Share icon
- Background Edit icon
- Desert/Trail icon
- other bar/pill icons

Do not maintain separate hard-coded icon colors that ignore Text Color.

==================================================
8. HOVER / ACTIVE / DISABLED STATES
==================================================

Preserve state meaning.

Text Color is the base color.

Allowed state effects:
- hover: white for Share as already user-approved
- disabled: reduced opacity
- active/open: border/ring/shade distinction
- selected: outline/shade/contrast distinction

Do NOT revert the entire component to default gray merely because it is:
- active
- selected
- open
- disabled
