PROMPT 023S — REDUCE THE SPACE BETWEEN CATEGORY BARS BY 1/2 OF THE CURRENT SPACING

RECOMMENDED REPLIT MODE: ECONOMY

WHY:
This is a small, low-risk visual spacing adjustment. It should not require Power mode.

PURPOSE

Reduce the empty vertical space BETWEEN adjacent collapsible category bars by 1/2 of their current spacing.

In plain language:
- Find the current gap between Category Bar A and Category Bar B.
- Reduce that gap by half.
- The new gap must be 50% of the current gap.

Example:
- if the current gap is 12 px, change it to 6 px
- if the current gap is 8 px, change it to 4 px

This request applies only to the empty space BETWEEN category bars.

DO NOT:
- make the category bars themselves shorter
- reduce padding inside a category bar
- change spacing between item rows inside an expanded category
- change expanded-content padding
- change borders, radius, colors, transparency, font, text size, icons, or expand/collapse behavior
- change unrelated panel spacing
- perform unrelated refactors
