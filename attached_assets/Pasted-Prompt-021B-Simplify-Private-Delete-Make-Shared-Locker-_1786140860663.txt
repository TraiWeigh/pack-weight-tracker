==================================================

Required flow:

Owner clicks Delete
→ show simple confirmation such as:

Buttons:
Cancel
Permanently Delete

No password field.
No Clerk password verification.
No secondary TrailWeigh password.
No account re-verification.

Cancel:
- nothing deleted.

Permanently Delete:
- delete ONLY the selected file belonging to the signed-in owner.

Preserve ownership checks.

Do NOT allow deletion merely because a file ID is known.

Do NOT remove authentication requirements from /checklist.

==================================================
5. TEMPORARY VIEWER EDITS
==================================================

Shared viewers may interact with the shared file during their session, including existing supported temporary edits.

Examples may include:
- checked/unchecked state
- quantities
- weights
- other editable checklist values already supported in shared mode

These changes are TEMPORARY.

They must NEVER:
- write to sender's original Locker file
- overwrite sender's saved state
- rename sender file
- delete sender file
- alter sender background/appearance
- propagate back through cross-tab/localStorage/IndexedDB/server persistence

Refresh/reopen may restore the original shared snapshot according to current Share behavior.

==================================================
6. SAVE TO VIEWER'S OWN ACCOUNT ONLY
==================================================

The ONLY persistence path for a shared viewer is:

Save Your Own Copy

Required:

- If signed out, send viewer through the existing sign-in/account-creation path.
- Preserve the intended shared file through that flow where existing architecture supports it.
- Create a new independent file in VIEWER'S account.
- Assign a new independent file ID.
- Preserve the copied gear/content and supported appearance.
- Viewer may then rename/edit/delete THEIR OWN copied file through normal private Locker behavior.

The copied file must NOT remain linked to sender's original.

Viewer changes after copying:
→ affect viewer copy only.

Sender changes later:
→ must not overwrite viewer copy.
