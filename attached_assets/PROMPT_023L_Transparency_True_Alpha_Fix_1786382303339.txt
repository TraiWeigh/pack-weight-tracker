PROMPT 023L — FIX TRANSPARENCY: TRUE BACKGROUND ALPHA FOR CUSTOMIZABLE BARS/PILLS

PURPOSE

Fix the existing Transparency control in TrailWeigh.

The Transparency slider currently moves, but it does NOT create true transparency. Instead, the customized bars/pills become darker or shift toward black/navy. The background image is not actually revealed through the surfaces.

This prompt is ONLY for fixing Transparency behavior.

Do NOT redesign the appearance system.
Do NOT change theme ordering or theme images.
Do NOT change Bar Color behavior except as required to preserve the selected color while applying alpha.
Do NOT remove the native color picker/eyedropper.
Do NOT test the native macOS eyedropper during this prompt.
Do NOT work on unrelated UI issues.

==================================================
1. CURRENT FAILURE
==================================================

The Transparency slider exists and moves.

Current incorrect behavior:

- moving the slider toward "Transparent" changes the customized bar/pill surfaces to a darker shade
- some surfaces appear black/navy
- the background image does NOT become increasingly visible through the bar/pill
- this is NOT true transparency

The likely issue may involve color mixing, dark overlays, opacity calculations, theme fallback colors, or applying opacity incorrectly.

Inspect the actual implementation before deciding the cause.

Do not assume the cause.

==================================================
2. REQUIRED TRANSPARENCY BEHAVIOR
==================================================

The slider must control ONLY the alpha/transparency of the customizable bar/pill BACKGROUND surface.

Required behavior:

LEFT:
more transparent

RIGHT:
more solid / opaque

Preferred endpoint labels:

Transparent        Solid

At the far-right / Solid position:

- surface alpha = fully opaque
- selected Bar Color appears normally

As the slider moves left:

- keep the SAME selected Bar Color hue
- reduce ONLY the background alpha
- the TrailWeigh background image/theme should become increasingly visible through the bar/pill surface

At the far-left / Transparent position:

- surface background should be highly transparent or fully transparent, according to the current slider design
- text and icons must remain readable
- the background image/theme must visibly show through

IMPORTANT:

Do NOT simulate transparency by:
- darkening the selected color
- blending it toward black
- blending it toward navy
- changing brightness
- reducing saturation
- applying a dark overlay
- switching to a different fallback background color

Use real alpha transparency.

==================================================
3. DO NOT USE WHOLE-COMPONENT CSS OPACITY
==================================================

Do NOT apply CSS `opacity` to an entire bar/pill/container.

That would also fade:

- text
- icons
- chevrons
- drag handles
- trash icons
- counts
- units
- nested controls

Instead, apply alpha only to the background surface.

Examples of acceptable implementation approaches include:

- RGBA / HSLA with alpha
- modern color syntax with alpha
- a background layer/pseudo-element that receives alpha while content remains fully opaque

Choose the smallest approach that fits the existing code architecture.
