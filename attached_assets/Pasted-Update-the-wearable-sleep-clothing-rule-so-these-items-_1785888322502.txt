## Correct destination

For wearable sleep or camp clothing, use this destination priority:

1. Existing category named “Clothing”
2. Existing category named “Clothing System”
3. The application’s canonical regular-clothing category
4. Manual review if no regular-clothing category exists

Do not place these items in:

- Clothing Worn
- Worn Clothing
- Worn Items
- Worn Weight

## Required distinction

“Clothing” or “Clothing System” means clothing packed as part of the gear list.

“Clothing Worn” means clothing specifically designated as being worn while hiking or already worn at the start of the trip.

An item is not Clothing Worn merely because it is wearable.

Sleep clothing is normally packed clothing and must go into Clothing or Clothing System.

## Clothing Worn rule

Use Clothing Worn only when one of these conditions is present:

1. The individual row has an explicit category or status indicating:
   - Clothing Worn
   - Worn Clothing
   - Worn
   - Worn Weight
   - Wearing

2. The row appears under an explicit Clothing Worn section and there is no stronger rule identifying it as packed sleep or camp clothing.

Do not infer Clothing Worn merely from:

- The item being wearable
- The word “sleep”
- The word “camp”
- The word “socks”
- The word “hood”
- The source item being checked
- The item having a quantity of one

## Stable category roles

Keep separate canonical internal roles for:

- clothing — regular packed clothing
- clothing_worn — clothing explicitly designated as worn

If the user renames Clothing to Clothing System, preserve the canonical role:

clothing

If the user renames Clothing Worn, preserve the canonical role:

clothing_worn

Do not select between these categories using loose name similarity.

## Destination priority

Use this order:

1. Known Consumables Type → Consumables
2. Explicit individual-row worn status → Clothing Worn
3. Known sleep, camp, or insulated wearable Type → Clothing or Clothing System
4. Known Shelter Type → Shelter
5. Known Sleep equipment Type → Sleep System
6. Recognized source section
7. Manual review

A Sleep System section must not override a known wearable Type.

A generic wearable-item match must not automatically route an item to Clothing Worn.
