PRIMARY DEFECT / GOAL
============================================================

Update ONLY the main category accordion group so normal manual interaction follows
single-open accordion behavior while preserving the existing left-side Expand All / Collapse All
exception.

Required normal manual behavior:

A. ONE OPEN
- During ordinary manual use, only one main category may be expanded at a time.
- Opening Category B must automatically collapse Category A.

B. ZERO OPEN
- Zero main categories may be open.
- If exactly one category is open and the user clicks that same category, it closes.
- Do not force another category open.

C. EXPAND ALL EXCEPTION
- Existing left-side DOWN arrow = Expand All / Open All.
- Clicking it expands every main category simultaneously.
- This is the intentional exception to normal single-open behavior.
- All categories may remain open until the user interacts with an individual category
  or uses Collapse All.

D. RETURN TO NORMAL AFTER EXPAND ALL
- After Expand All, the NEXT individual category click must immediately return the group
  to normal single-open mode.
- If several/all categories are open and the user clicks Category C:
  Category C remains/becomes the ONLY open category.
- A subsequent click on Category C may then close it, leaving zero open.
- Do NOT leave several other categories open after that first individual interaction.

E. COLLAPSE ALL
- Existing left-side UP arrow = Collapse All / Close All.
- Clicking it closes every main category.
- It must work from:
  all open / several open / one open / none open.
