============================================================

First prove the enabled stacked bar works normally by TAP.

============================================================
4. TEST B — MID-DRAG PHYSICAL MOVEMENT
============================================================

Starting with the stacked bar INACTIVE:

1. Record BEFORE:
   - boundingClientRect top
   - boundingClientRect bottom
   - boundingClientRect height
   - computed transform
   - active state

2. Pointer/touch down near the center of the stacked bar.

3. While keeping pointer DOWN, drag upward approximately 80 px.

4. BEFORE releasing, record DURING:
   - boundingClientRect top
   - boundingClientRect bottom
   - computed transform
   - active state

5. Take a screenshot while the pointer is still held if possible.

PASS:
- top/bottom position remains effectively unchanged (<= 1 px layout tolerance)
- no lift/translate transform appears
- bar does not visually float/follow the finger
- active state remains unchanged

FAIL:
- the bar shifts upward/downward with the drag
- transform changes to a translate/lift state
- bar visibly lifts/floats/follows the pointer

Report exact pixel movement:
duringTop - beforeTop

============================================================
5. TEST C — DRAG/RELEASE MUST NOT ACTIVATE
============================================================

Repeat from an inactive state.

1. Pointer/touch down on the enabled stacked bar.
2. Drag upward far enough to exceed any existing lift/activation threshold.
   Use approximately 100–120 px.
3. Release.
4. Record:
   - active state after release
   - target order/position
   - final transform
   - whether the target became active

PASS:
- drag/release does NOT activate the stacked bar
- bar returns to original resting position
- active card remains unchanged

FAIL:
- stacked bar activates because of drag/release
- bar docks/changes active state without a tap

- account for it in the bar-position measurement
- do not falsely attribute parent scrolling to stacked-bar lift
