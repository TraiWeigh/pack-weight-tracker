- Save
- Save As

- Delete

- create viewer-owned independent copy

Do not lose the viewer's intended file/edits during sign-in where architecture supports preservation.

After copy:
- viewer may use normal private Rename/Delete/Save on THEIR OWN copy
- sender original remains unchanged
