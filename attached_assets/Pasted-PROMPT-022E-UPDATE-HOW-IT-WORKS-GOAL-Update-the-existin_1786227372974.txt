Update the existing TrailWeigh "How It Works" page.

Help & How-To already contains the detailed instructions from Prompt 022C.

2. USE THREE MAIN WORKFLOW SECTIONS
==================================================

Organize How It Works into these three main topics, in this exact order:

1. Create / Upload
2. Add / Organize
3. Save / Preview / Print / Share

These represent the normal TrailWeigh workflow:

CREATE → ORGANIZE → USE

Make each topic a clickable collapsible panel / accordion section.

IMPORTANT:
This is an accordion/collapsible panel, NOT a dropdown/select menu.

Requirements:

- Entire title row is clickable.

==================================================
3. CREATE / UPLOAD
==================================================

Keep this concise.

Explain that users can begin in either of two ways:

CREATE
- Start directly in TrailWeigh and build a gear list manually.

UPLOAD
- If the user already has a gear list, use Scan Gear List to upload/import a supported file.
- TrailWeigh detects items from the uploaded list.
- The user reviews the detected items before importing them.
- The user chooses which detected items to add.

IMPORTANT:

Scanning belongs here.

Do NOT create a separate "Scan Gear List" or "Importing" section on How It Works.

Use only file types actually supported by the current application.

Do not invent formats.

==================================================
4. ADD / ORGANIZE
==================================================

Explain that once gear is in TrailWeigh, the user can:

- Add additional gear manually.
- Enter or edit item information.
- Enter quantity and weight.
- Organize items into appropriate categories.
- Move items between categories using the current Move control if present.
- Check/select the gear being used for the current trip.
- Leave other gear unchecked when it is not being carried.

Also explain the usefulness of creating DIFFERENT GEAR LISTS for different hikes and conditions.

Include examples such as:

- PCT
- AT
- CDT
- PCT Desert
- PCT Sierra
- Summer
- Cold Weather
- Winter
- Weekend trips

Explain briefly:

A gear list that works for one trail or season may not be appropriate for another.

Different routes, elevations, climates, and seasons may require changes to:

- Clothing
- Insulation
- Shelter
- Rain protection
- Water capacity
- Traction
- Other condition-specific equipment

Do NOT prescribe what a user must carry.

The purpose is to show that TrailWeigh can be used to build separate checklists for different trips and conditions.

If Save As is the current method for creating a separate version of an existing saved list, mention that briefly, but leave detailed Save As instructions to Help & How-To.

==================================================
5. SAVE / PREVIEW / PRINT / SHARE
==================================================

Keep these related end-of-workflow actions together.

------------------------------------------
SAVE
------------------------------------------

Explain briefly that users can save named gear lists to their Locker so they can return to them later.

Mention that separate saved lists can be useful for:

- Different trails
- Different seasons
- Different gear configurations
- Different trips

Do not provide the full Save / Save As / Locker tutorial here.

That belongs in Help & How-To.

------------------------------------------
PREVIEW
------------------------------------------

Explain that Preview provides a clean formatted view of the current gear list before printing or sharing.

Use the actual current Preview behavior.

------------------------------------------
PRINT
------------------------------------------

Make the CHECKLIST usefulness clear.

Explain that TrailWeigh is not only for calculating weight.

The completed gear list can also be printed and used as a physical packing checklist.

Users can check items while:

- Gathering equipment
- Packing at home
- Preparing with another hiker
- Performing a final gear check before leaving for the trailhead

Use a concise idea similar to:

"A checklist can help prevent arriving at the trailhead only to discover an important piece of gear was left at home."

------------------------------------------
SHARE
------------------------------------------

Keep all sharing information here.

Explain that users can share their gear list using the current Share function.

Also explain, if supported by the current interface, that the user can share JUST THE CHECKABLE PACKING LIST.

The shared checkable list can allow the recipient to:

- View the packing list.
- Check items off while gathering or packing gear.
- Print the list.

The recipient's temporary checkbox changes must not modify the owner's saved original.

This can be useful for:

- Hiking partners
- Trip planning
- Helping another hiker prepare
- Giving someone a packing checklist to work from

Do NOT create a separate:

"Share a Checkable Packing List"

topic.

It belongs inside Share.
