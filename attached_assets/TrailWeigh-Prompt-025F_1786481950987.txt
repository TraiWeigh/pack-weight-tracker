PRIMARY GOAL

Apply accordion-style behavior to the ENTIRE sidebar panel group.

NORMAL INDIVIDUAL PANEL BEHAVIOR

By default:

- Opening one sidebar panel automatically closes all other sidebar panels.
- Only one sidebar panel should remain open at a time during normal individual panel use.
- The user may close the currently open panel, leaving all sidebar panels closed.
- Do NOT force one panel to remain open.

Examples:

If Pack Summary is open and the user opens Weight Distribution:
- Weight Distribution opens.
- Pack Summary closes.
- all other sidebar panels remain closed.

If Scan Gear List is open and the user opens Pack Summary:
- Pack Summary opens.
- Scan Gear List closes.
- all other sidebar panels remain closed.

This behavior must apply to the whole sidebar panel group, not only two named panels.

EXPAND ALL CONTROL

Preserve the existing group Expand All arrow/control.

When the user clicks Expand All:

- open EVERY sidebar panel in the group at once;
- do not close panels because of the normal single-open rule;
- this action intentionally overrides normal accordion behavior.

The user should be able to see all sidebar panels expanded after one click.

COLLAPSE ALL CONTROL

Preserve the existing group Collapse All arrow/control.

When the user clicks Collapse All:

- close EVERY sidebar panel in the group.

This must work regardless of current state:

- if all panels are open -> close all;
- if several panels are open -> close all;
- if only one panel is open -> close that one;
- if all panels are already closed -> remain closed.

IMPORTANT:
Collapse All always means "close every sidebar panel."

AFTER EXPAND ALL

After Expand All opens every panel:

If the user then clicks an individual sidebar panel header:

- return to normal single-open accordion behavior for that interaction.

Required behavior:
- if the clicked panel is currently open and the user is closing it, close that panel normally;
- if the user opens/selects an individual panel after the all-open state, the clicked/opened panel should become the only open panel and the others should close.

Do not keep the sidebar permanently in a special "all open" mode after the user resumes individual interaction.

This includes all collapsible panels controlled by the sidebar group expand/collapse controls, such as current panels like:
- Pack Summary

- Locker / Shared Files or other current sidebar panels if they are part of the same sidebar group
