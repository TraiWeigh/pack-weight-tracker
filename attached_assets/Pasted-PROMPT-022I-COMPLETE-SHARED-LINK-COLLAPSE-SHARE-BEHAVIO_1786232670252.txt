==================================================

- Do NOT create a new owner record merely because a recipient re-shares an existing shared link.
- Preserve the immutable/shared-snapshot ownership model.
- Do not grant additional permissions.

Use the best supported browser sharing behavior already available in TrailWeigh.

Where appropriate:

1. Use the browser-native Web Share API when available.
2. Otherwise provide a Copy Link fallback.

Provide clear success feedback such as:

or the existing TrailWeigh equivalent.

Do not expose internal IDs/tokens in visible explanatory text beyond the normal URL.

10. SHARE CHECKABLE PACKING LIST
==================================================

Provide a distinct sharing option for users who want to share JUST A SIMPLE CHECKABLE PACKING LIST rather than the full TrailWeigh application view.

This is an intended TrailWeigh feature and must not be represented merely as a PDF.

The shared checkable packing list should:

- Show the relevant gear-list item descriptions.
- Preserve the owner's/shared snapshot's initial checked/selected items as appropriate to the packing list.
- Allow the recipient to check/uncheck items locally while packing.
- Keep those recipient changes temporary.
- Never modify the owner's saved original.
- Be usable without exposing owner-only file-management controls.
- Be printable.
- Reset temporary recipient checkbox changes according to the current shared-session model on refresh/reopen unless an existing intentional viewer persistence mechanism says otherwise.

The purpose is a straightforward packing checklist.

Do not make the recipient navigate through the full gear-management interface merely to check off packed items.
