7. ITEM ROWS — THE ONLY SCROLLING PART
============================================================

In active long-category mode:

ONLY the item-row region scrolls.

Required:
- item rows scroll upward underneath the fixed category-header boundary
- item rows scroll downward underneath the fixed Add Item boundary
- visually clip/mask item rows to the item viewport so they do not paint over the header or Add Item bar
- normal finger vertical scrolling works inside this bounded item region
- do not show ugly browser scrollbar chrome
- do not create horizontal overflow

Preserve:
- item selection/checking
- item editing
- slide-to-delete
- category long-press reorder
- category open/close
- bottom box-group horizontal gestures

Do not allow a vertical item swipe to accidentally move the bottom box group.
