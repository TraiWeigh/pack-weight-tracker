PROMPT 022N — INCREASE SIGN-IN CONTRAST & FIX CONTINUE BUTTON STATES

GOAL

Correct the remaining visibility problems on TrailWeigh authentication forms.

USER TEST RESULT FROM PROMPT 022M

The previous change improved the screen slightly, but the controls are still
far too light.

Current problems visible in user testing:

1. Email Address input still blends into the white authentication card.
2. Continue with Google still has a boundary/text treatment that is too faint.
3. Continue currently appears as a dark-green pill with BLACK text.
4. The enabled/disabled Continue states are not visually clear enough.

Do NOT redesign the authentication page.

This is a contrast and button-state correction only.

==================================================
1. EMAIL INPUT — MAKE IT OBVIOUS
==================================================

The Email Address input needs substantially MORE visual contrast than the
current implementation.

In LIGHT MODE:

Use a clearly visible medium neutral-gray border.

Target appearance approximately equivalent to:

Border:
#9CA6A0 to #A8B0AC

Background:
#F5F6F5 to #F7F8F7

Do not use an almost-white border.

The field must be immediately recognizable against the white authentication
card BEFORE the user clicks it.

The goal is:

WHITE CARD
+
CLEAR LIGHT-GRAY INPUT SURFACE
+
VISIBLE MEDIUM-GRAY BORDER

The user should not need to search visually for the input box.

==================================================
2. PLACEHOLDER TEXT — DARKER
==================================================

The current placeholder:

Enter your email address

is still too light.

Make placeholder text visibly darker.

Use approximately a medium gray with sufficient readability.

Do NOT use pale gray text that nearly disappears.

The placeholder should still look secondary to entered text, but it must be
easy to read.

==================================================
3. GOOGLE BUTTON — STRONGER BOUNDARY
==================================================

The Continue with Google button is still too faint.

In Light mode:

- Give it the same clearly visible medium-gray border family as the input.
- Keep its background white or very lightly tinted.
- Make "Continue with Google" clearly readable.
- Preserve the Google logo.
- Keep it visually secondary to the main Continue button.

Do NOT use nearly invisible gray text.

The complete button outline should be obvious.

==================================================
4. CONTINUE BUTTON — ENABLED STATE
==================================================

When Continue is ENABLED:

Use the existing TrailWeigh dark/medium green primary-button background.

The button text MUST be:

WHITE or very near white.

DO NOT use black or dark text on the TrailWeigh dark-green primary button.

Expected visual relationship:

DARK TRAILWEIGH GREEN BACKGROUND
+
WHITE "Continue" TEXT
+
WHITE/LIGHT ARROW ICON

Maintain sufficient contrast.

==================================================
5. CONTINUE BUTTON — DISABLED STATE
==================================================

When the Email Address field is empty or invalid and Continue is DISABLED:

Do NOT display the same dark-green primary-button appearance.

The disabled state should look clearly unavailable.

Use a lighter muted treatment such as:

- Light gray-green / neutral background
- Medium-gray text

or the closest appropriate TrailWeigh design token.

IMPORTANT:

The disabled button must remain clearly visible as a button.

Do NOT make it disappear into the page.

But it must also be immediately distinguishable from the ENABLED dark-green
button.

Conceptually:

DISABLED:
muted/light background + readable muted text

ENABLED:
TrailWeigh green + WHITE text

==================================================
6. BUTTON STATE TRANSITION TEST
==================================================

Test this exact sequence:

A. Open Sign In with Email Address empty.

Expected:

[ ] Continue is visibly DISABLED.
[ ] Continue is NOT dark green.
[ ] Button shape is still clearly visible.
[ ] Text remains readable.

B. Enter a valid email address.

Expected:

[ ] Continue switches to TrailWeigh green.
[ ] Text becomes WHITE.
[ ] Arrow becomes WHITE/light.
[ ] It clearly looks clickable.

C. Remove the email address.

Expected:

[ ] Continue returns to the disabled visual state.

==================================================
7. FOCUS STATE
==================================================

When the Email field receives focus:

Use a clearly visible TrailWeigh-green focus treatment.

The focused control should be noticeably different from the unfocused state.

Use:

- Green border and/or
- Accessible focus ring

Do NOT make the focus effect so faint that it cannot be seen.

==================================================

- Email address

- Don't have an account?
- Sign up

Do not unnecessarily darken everything to black.

But any functional/instructional text must be comfortably readable.

==================================================

The finished Light-mode screen should have this visual hierarchy:

WHITE PAGE

WHITE AUTHENTICATION CARD

CLEARLY DEFINED GOOGLE BUTTON
↓
CLEARLY DEFINED EMAIL INPUT
↓
