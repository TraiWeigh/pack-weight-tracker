PHASE 3 — MINIMUM SAFE FIX

Use the smallest safe fix.

Preferred solutions, in order:

1. If this is only a simple z-index mismatch:
   - give the Share dropdown/menu layer a z-index above the sidebar group using the application's existing layering conventions.

2. If a parent stacking context prevents z-index from working correctly:
   - render/portal the Share dropdown into document.body or the application's existing overlay/portal root;
   - preserve its current screen position and anchoring to the Share control.

3. If overflow clipping is the confirmed cause:
   - correct only the specific clipping/overlay structure necessary for the Share menu;
   - do not broadly remove overflow protections that other layout behavior depends on.

Choose the smallest robust solution based on the actual cause.

IMPORTANT:
A portal is acceptable if needed, and TrailWeigh has already used portal-style overlay repairs elsewhere.
Do not use a portal unless the current stacking context actually requires it.
