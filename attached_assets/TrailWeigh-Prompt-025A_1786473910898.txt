PRIMARY PROBLEM

Many people make Word packing lists without using Microsoft Word's formal Heading 1/Heading 2 styles.

Instead they often format category labels like this:

Backpack   <-- ordinary Normal paragraph, bold text
[table follows]

Shelter    <-- ordinary Normal paragraph, bold text
[table follows]

Those visually obvious bold labels should be usable as category context when they clearly function as a category label for the table immediately following them.

PRIMARY GOAL

For DOCX import only:

Support a conservative fallback where an ordinary Word paragraph can supply category context when ALL of the following are true:

1. It is NOT already a Word Heading 1/Heading 2 paragraph.
2. Its visible text is substantially/all bold.
3. It is a short standalone paragraph.
4. It is immediately followed by, or structurally associated with, a compatible gear-item table.
5. The text is a meaningful category label or safely normalizes to one.

This fallback must come AFTER the existing real Heading 1/Heading 2 support.

DO NOT TREAT EVERY BOLD PARAGRAPH AS A CATEGORY.

DETECTION RULE — CONSERVATIVE

A plain paragraph may become category context only when it strongly looks like a category label.

At minimum consider:
- paragraph style is not Title/Subtitle/Heading;
- paragraph is short;
- text is substantially/all bold;
- paragraph has no list/bullet numbering;
- paragraph is immediately before a compatible item table, allowing only empty spacer paragraphs if necessary;
- following table has recognizable item headers such as Type / Name / Weight / Unit / Qty.

Do not use only font size.
Do not use only boldness.
Do not use only capitalization.

STRUCTURAL ASSOCIATION IS IMPORTANT

The strongest signal is:

plain bold standalone paragraph
+
next meaningful block is a compatible item table.

This should allow:
Backpack + item table

while rejecting:
Trip Notes + ordinary body paragraph

Do not let a bold note several paragraphs above a table become category context.

CATEGORY NORMALIZATION

Feed accepted plain-bold labels through the same existing category normalization and semantic routing used by formal Word headings.

Do not create a second category system.
