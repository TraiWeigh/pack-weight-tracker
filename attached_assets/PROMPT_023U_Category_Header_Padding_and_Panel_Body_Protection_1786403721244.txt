PROMPT 023U — REDUCE CATEGORY HEADER VERTICAL PADDING BY 50% + PROTECT EXPANDED PANEL BODIES

RECOMMENDED REPLIT MODE: ECONOMY

WHY:
This is a focused UI/CSS correction. It changes category-header vertical padding and protects expanded accordion body styling. It should not require Power mode unless inspection reveals an unexpected shared-style architecture problem.

PURPOSE

Make two focused changes:

A. CATEGORY HEADER DENSITY
Reduce the vertical padding ABOVE and BELOW the text/icons inside each collapsible category header bar by exactly 50% of the current value.

B. EXPANDED PANEL BODY PROTECTION
Expanded collapsible-panel body/content areas must NOT be affected by:
- Bar Color
- Transparency
- Text Color

- Font
- Font Size, if/when that setting exists in the current implementation

Do NOT add a new Font Size control in this prompt if one does not already exist.

Panel/header bars and intended pills/controls may continue using Bar Color, Text Color, and Transparency.
