==================================================

Private Locker deletion is an authenticated owner-only action.

SIGNED OUT:

- cannot delete a private Locker file
- any existing direct client/server delete path must reject an unauthenticated attempt

SIGNED IN:

- deletion occurs ONLY after successful secure account re-verification
- wrong credentials → nothing deleted
- cancel → nothing deleted
- successful verification → only the selected user-owned file is deleted
