==================================================
B — COLLAPSIBLE-PANEL DISCLOSURE CHEVRONS
==================================================

Terminology:

These are DISCLOSURE CHEVRONS on COLLAPSIBLE PANELS / ACCORDION SECTIONS.

They are NOT ordinary dropdown/select arrows.

The chevron should tell the user WHICH DIRECTION THE PANEL WILL MOVE IF CLICKED NEXT.

REQUIRED BEHAVIOR:

COLLAPSED / CLOSED panel:
Chevron points DOWN.

Meaning:
Clicking it will expand/open the panel downward.

EXPANDED / OPEN panel:
Chevron points UP.

Meaning:
Clicking it will collapse/close the panel upward.

Use this rule consistently everywhere a chevron controls a collapsible panel.
