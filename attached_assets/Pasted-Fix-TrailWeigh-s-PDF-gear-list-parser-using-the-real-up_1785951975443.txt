## Understand the real PDF structure

The real PDF contains:

### Pages 1–4: actual gear checklist

Category headers follow this pattern:

- X Backpack Description Weight Add
- X Shelter Description Weight Add
- X Sleep Description Weight Add
- X Clothing Packed Description Weight Add
- X Kitchen Description Weight Add
- X Electronics Description Weight Add
- X Toiletries + Med Description Weight Add
- X Hydration Description Weight Add
- X Clothing Worn Description Weight Add
- X Miscellaneous Description Weight Add

Gear rows follow this general structure:

`TRUE/FALSE + Type + Description + Weight + Add`

Examples:

- FALSE Backpack ULA Ultra Circuit 40.8 0
- TRUE Backpack Zpacks Nero Classic Backpack 14 14
- FALSE Tent Zpacks Free-Zip 2 with poles / repair kit 36.8 0
- TRUE Ground Sheet Zpacks Nylo Pro Groundsheet 5' x 8' 4 4
- FALSE Sleeping Bag UGQ Bandit 10F 26 0
- TRUE Puffy Jacket Enlightened Torid Jacket 10.2 10.2

The final two numbers are:

1. Weight
2. Add

TrailWeigh must use the Weight value, not the Add value.

### Pages 5–8: summary and auxiliary tables

These pages include:

- Unit / Qty columns
- Category Weight Unit
- Backpack, Shelter, Sleep summary totals
- Base Weight
- Expendables
- Total
- First Aid Kit
- Repair Kit
- Empty rows and unit-only values

These are not normal gear-list rows and must not be imported.

### Pages 9–10: Meal Planner

These pages contain meal and nutrition information.

Do not import any Meal Planner rows as gear.

## Parse page-by-page

Parse each page separately so page boundaries and section context are preserved.

## Gear-row parsing

For each candidate gear row:

1. Remove a leading TRUE or FALSE checkbox value.
2. Extract Type.
3. Extract Description.
4. Extract Weight.
5. Ignore the Add value.
6. Assign the current category.
7. Set the imported checkbox state to unchecked.

The parser must support multi-word Types and Descriptions.

Examples that must remain intact:

- Pack Liner
- Ground Sheet
- Tent Stake

- Trekking Pole

Do not merge TRUE/FALSE into the Type.

For example:

`FALSEPack Liner`

Correct:

## Weight handling

The PDF values in the gear tables are ounces unless a row explicitly includes another unit.

Do not convert summary values expressed in pounds into fake gear-item ounces.

Examples:

- ULA Ultra Circuit = 40.8 oz
- Zpacks Nero Classic Backpack = 14 oz
- Zpacks Free-Zip 2 = 36.8 oz
- UGQ Bandit 10F = 26 oz
- Fire-Maple Petrel G3 Pot = 5.7 oz

Do not use:

- Add values
- Category totals
- Base Weight
- Expendables
- Total
- Unit / Qty numbers
