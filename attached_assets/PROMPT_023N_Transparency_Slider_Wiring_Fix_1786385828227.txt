==================================================
4. INSPECT THE ACTUAL SLIDER IMPLEMENTATION
==================================================

Find the exact Transparency slider component/control.

Inspect:

- `value`
- `defaultValue`
- `min`
- `max`
- `step`
- `onChange`
- `onInput`
- `onValueChange`
- `onValueCommit`
- any percentage conversion
- any `1 - value` inversion
- any string-to-number conversion
- any clamping
- any debouncing/throttling
- any state selector
- any duplicate/local component state
- any effect that reloads the value from storage after interaction

Look specifically for mismatches such as:

- UI range 0–100 while state expects 0–1
- state 0–1 while UI sends strings
- "Transparent" direction reversed
- slider uses `defaultValue` instead of controlled `value`
- visual thumb moves from local state but BarStyleContext never changes
- wrong setter used
- setter updates a stale/duplicate state object
- persistence effect immediately overwrites the new value
- an `onValueCommit` updates storage but `onValueChange` does not update live state
- input event handled on the wrong element

Do not assume which one is happening. Trace it.
