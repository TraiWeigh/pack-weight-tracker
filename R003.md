## R002Q Corrections

| Issue | Result | Evidence |
|---|---|---|
| A1 Long-deck scrolling | FIXED | Gesture now mode-locks after an 8px slop: if the deck overflows (`canDeckScroll()`), ANY vertical drag becomes a pure bidirectional scroll (1:1, reversible) and can never activate a bar on release; tap (<8px) always activates; drag-to-dock remains only for non-overflowing decks. Test: 20 seeded locker entries — upward drag increases `scrollTop`, downward drag decreases it, no card activates ("long deck: touch drag scrolls BOTH directions…" PASS). |
| A2 Active-title synchronization | FIXED | Locker "Load This List" now calls `setListName(entry.name)` alongside the store swap, so Save/Share use the loaded name. Test: load seeded entry → `active-list-name` shows exactly the entry name (PASS). |
| A3 Disabled surface opacity | FIXED | Container opacity is always `1` with an opaque background; only the icon (0.45) and text content (0.5) are muted. Test asserts computed container opacity === 1 and muted content opacity < 1 (PASS). |
| A4 Safe-area offset | FIXED | Nav height is measured via a callback ref + `ResizeObserver` (observing the **border-box**, since safe-area insets grow padding only) and passed as the single `bottomOffset` to deck and backdrop. `paddingBottom` uses `var(--tw-safe-bottom, env(safe-area-inset-bottom, 0px))` so tests can inject a nonzero inset. Tests: baseline deck/backdrop bottoms equal measured nav height; injecting a 34px inset grows the nav ≥28px and the deck sits exactly on its top edge (both PASS). |

Two real bugs were found and fixed while proving A4:
1. `ResizeObserver` defaults to content-box, which never fires on padding-only growth → observe `{ box: 'border-box' }`.
2. The component's loading gate meant a one-shot `useEffect` saw a null nav ref → replaced with a callback ref that attaches the observer whenever the nav mounts.
