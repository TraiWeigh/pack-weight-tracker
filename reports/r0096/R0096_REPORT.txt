THREE STANDING REPLIT QUESTIONS
1. What did you learn that improves future prompts?
   The R0095 shell is easiest to extend by adding a shared shell slot and adjusting main-scroll
   clearance. The active long-category header should be sticky within that same scroll viewport,
   not duplicated with a new fixed offset.
2. What was unclear, unnecessary, risky, or better expressed?
   "Active/over-expanded" needed translation to the current isCatLong bounded-mode state. Making
   the requirement explicitly apply to every view mode, including Photo, avoids a subtle
   state-dependent gap.
3. What Replit/project guidance helps next time?
   Run the focused Playwright suites with one worker. Real iPhone evidence outranks the passed
   Chromium geometry. The existing drawer is an absolute child of the fixed shell, so frame
   stability comes from separating its interior overflow rather than adding viewport compensation.
   When new Add Item creation flows change (e.g. R0102 accordion), update every helper that
   calls cat-add-item-btn directly — viewport-safe.spec.ts had a stale direct-click loop.
