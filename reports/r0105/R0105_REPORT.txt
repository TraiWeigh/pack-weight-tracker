R0105 — Bottom Camera / Photos: contextual photo entry
=======================================================
Date: 2026-08-21
Branch: main
Build: pack-checklist (Vite / React / TypeScript)

OBJECTIVE
---------
Replace the stub "coming in a future update" toasts on the Bottom Box Group 3
Camera and Photos buttons with the existing working photo system, using fully
contextual logic to determine the photo destination.

BEHAVIOURAL CONTRACT (all three branches)
------------------------------------------
Case 1 — Item expanded:
  Both Camera and Photos target the currently expanded item directly. No new
  item is created. The photo-edit-sheet opens (shows Take New Photo / Upload
  New Photo / Delete Photo if applicable / Cancel).

Case 2 — Category open, no item expanded:
  A new blank item is inserted at the bottom of the open category. The
  photo-edit-sheet opens for that new item. The appropriate native file input
  (.click()) is also triggered immediately, preserving Camera vs Photos intent
  within the same user-gesture stack so iOS Safari grants the permission.

Case 3 — No single category open (or allExpanded = true):
  A category-picker bottom sheet appears ("cat-photo-picker"). The user picks
  a destination category. One new blank item is created in that category; the
  category is opened (setOpenCatName); the photo-edit-sheet opens; and the
  appropriate native file input is triggered.
