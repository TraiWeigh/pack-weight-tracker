R0106 GS — Enable Photo List Creation
=====================================

Scope implemented
-----------------
- Enabled Add → New List in /mobile-functional-v3.
- Added Standard List and Photo List creation choices.
- Added the Photo List flow: New List → Photo List → Name List → clean start state.
- Added a backward-compatible optional Locker entry field:
  listKind: "standard" | "photo".
- Missing listKind remains standard mode for legacy Locker entries.
- Photo List mode persists through Save, Save As, Locker load, and browser reload.
- New Photo Lists begin empty with a distinct Photo List identity and Add Photo entry.

- R0097, R0098, R0099, R0101, and R0102–R0105 protected behavior was left
  unchanged and regression tested.
- R0100 shadow work was not changed.

  location thumbnails, photo assignment, or Save to Master List.
- The Add Photo button is a clear start-state affordance only; the later
  Photo List capture workflow is intentionally out of scope for R0106.
