R0107 GS — Physical iPhone Photo Capture and Footer Repair
===========================================================

Scope implemented
-----------------
- Replaced the R0106 Photo List Add Photo placeholder with a real source sheet.
- The source sheet exposes Camera and Photos and invokes the existing hidden
  native file inputs directly from the user action for iOS Safari compatibility.
- A captured/selected image is compressed to a TrailWeigh-owned JPEG data URL and
  retained at the Photo List level as an intentionally unassigned image.
- The retained image appears in the Photo List start state and survives Save,
  Save As, Locker reopen, and reload through the existing Locker payload.
- No category or item is fabricated while the image is unassigned.
- Added a bounded visible-bottom occlusion correction to the existing R0097 shell
  footer calculation. It preserves the layout viewport as the shell baseline and
  subtracts only the measured portion Safari reports as physically occluded.
