   geometry work separable from Safari browser-chrome behavior, and use commit history for
   exact visual rollback values rather than screenshots or estimates.

   The prompt clearly and safely constrained the rollback. The explicit instruction to
   preserve R0087 row density prevented an overly broad revert. The only unavoidable
   limitation is that Chromium cannot validate dynamic Safari chrome, so the final user
   iPhone check remains essential.

   its padding automatically restores spacer reservation through the existing ResizeObserver
   path; do not hardcode a duplicate height. Use package-specific typecheck and isolated
   Playwright output because wider project workflows include unrelated legacy failures.
