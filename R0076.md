## 2. Changes Made

### 2.1 Bounded item viewport (change 1)

**Problem:** R0075 placed the Add Item bar inside the item container div. When a category had many items the Add Item bar scrolled off-screen and the category card extended past the nav bar.

**Solution — three-part restructure:**

```
┌── category card ──────────────────────────────────┐
│  [CARD_H=68px] category header (wedge + name)     │  ← always visible
├──────────────────────────────────────────────────┤
│  item rows  ←  bounded div                        │  ← scrolls independently
│  maxHeight = navTop − summaryBtm − CARD_H − 44   │    when isCatLong
├──────────────────────────────────────────────────┤
│  [44px] Add Item bar                              │  ← always pinned below items
└───────────────────────────────────────────────────┘
```

- **`isCatLong` state** — set to `true` 420 ms after a category opens when `itemsEl.scrollHeight > availH + 4`.
- **`availItemH` state** — computed from **actual DOM positions** (`summaryBar.getBoundingClientRect().bottom` and `navEl.getBoundingClientRect().top`) at the moment `isCatLong` activates. This avoids stale React state that caused a ~53 px misalignment.
- **Item container** gets `maxHeight: availItemH`, `overflowY: auto`, `overflowX: hidden`, `scrollbarWidth: none` when bounded.
- **`recalcCatOverflow`** reads `openCatItemsRef.current.scrollTop / scrollHeight / clientHeight` directly (not main-scroll).
- **`scrollCatItems`** scrolls `openCatItemsRef.current` (not main-scroll).
- Triggers: `useEffect([isCatLong, recalcCatOverflow])` fires `recalcCatOverflow()` after 60 ms.

### 2.2 Add Item for empty categories (change 2, 4)

Old guard: `{isOpen && items.length > 0 && <div>…<AddItemBar/>…</div>}`.  
New: Add Item bar rendered in a **separate** `{isOpen && (…)}` block outside the item container. Always shown when a category is open, regardless of `items.length`.

### 2.3 Overflow chevron (change 3)

- Moved from inside the item container to the **Add Item bar** (which is now always pinned).
- `aria-label` changed from `"Scroll down/up to see more items"` → `"Show later items"` / `"Show earlier items"`.
- Scrolls `openCatItemsRef.current` instead of main-scroll.
- Only renders when `isCatLong && openCatName === catName && !allExpanded`.

### 2.4 Summary chevron position (change 5)

`marginRight: 48` added to the expand/collapse chevron button. The flex-1 left block absorbs the margin, shifting the chevron ~48 px left. Measured: chevron↔selected-block gap = **62 px** (was ~0 px in R0075).

### 2.5 Weight Distribution theme dropdown removed (change 6)

`<WeightDistribution paletteKey="trail" onPaletteChange={…}/>` replaced with inline `<MobileWeightDistribution>` in both the summary deck card and the `SummaryOverlay`. The Trail / Ocean / Sunset / Forest / Berry / Desert button no longer exists anywhere in the DOM.

### 2.6 Pie slices use wedge colours (change 7)

`MobileWeightDistribution` (defined at module level before `SummaryOverlay`) uses:
- `getCategoryTheme(s.name, i).bg` for every Recharts `<Cell fill>`.
- Legend rows carry `data-cat-name` and `data-cat-color` for test verification.
- G01 confirms 5/5 legend colours match wedge `getComputedStyle(el).backgroundColor`.
