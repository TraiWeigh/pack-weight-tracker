The three-slider navigation model (left drawer slider, right plus-panel slider,
bottom More panel + drag handle) has been fully retired and replaced with the
Bottom Card-Deck Navigation System: a 5-tab bottom bar where Locker, +, Search,
and More each raise a stacked card deck above the tab bar.

## Deck contents (all wired to existing functionality)

- **Locker** — one card per saved list (`readLockerEntries()`, newest first) with
  save date, category/item/selected counts, selected weight, and a
  **Load This List** button (loads via the standard sandbox mutation path, so it
  is undoable). Empty state note when no lists are saved.
- **+ (Add)** — Add Item (category picker → existing `addItem`, opens that
  category), Add Category (inline input → existing `addCategory`), Scan / Import
  (opens the existing scanner overlay), Create New List (**disabled** — guided
  creation does not exist yet; per spec, nothing is invented).
- **Search** — all three cards (Current List / Locker / Catalog) are **disabled**
  with honest "Not available yet" labels. Decision: no search implementation
  exists in V3; the spec forbids wiring non-existent functionality, so the deck
  presents future search families truthfully rather than inventing a client-side
  filter.
- **More** — five family cards:
  - *List Actions*: Save, Undo, Redo (disabled when history empty), Reset,
    Expand/Collapse All, **Checklist** and **Summary** (relocated here from the
    retired left drawer / Summary tab — both overlays preserved unchanged).
  - *Share & Print*: Share (review link), Print.
  - *List Settings*: imperial/metric toggle.
  - *Help & TrailWeigh*: Help, About, How It Works, Sources, Report a Problem, Contact.
  - *Account & Privacy*: Privacy, Terms, Delete Account (authenticated only),
    Affiliate Disclosure, Accessibility.

## Accessibility

- Decks are **non-modal** `role="dialog"` containers (no `aria-modal`) — the tab
  bar intentionally stays operable while a deck is open, so modal semantics
  would be contradictory. Focus moves to the deck's Close button on open.
- Cards are keyboard-operable (`Enter`/`Space`) with a visible focus outline.
- Disabled cards carry `aria-disabled="true"` and "not available yet" labels.
- A cancelled pointer gesture only resets drag state — it can never activate a
  card (fixed after code review).
